# LiveTrans Releases

Public downloads for LiveTrans, a Windows utility for real-time screen, manga, and web translation to natural Thai with seamless in-image overlays, 100% free Offline Local AI, and Gemini API support.

## Download

Get the latest version from the [Releases](../../releases) page:

- **LiveTrans-Offline-win64.zip** — 100% free Offline Edition (no API key or external apps required; downloads your chosen Thai GGUF model once inside the app).
- **LiveTrans-API-win64.zip** — Lightweight Cloud/API Edition (supports Google Gemini API, OpenAI-compatible APIs, and Ollama).

## Requirements

- Windows 10 or later (64-bit)
- **Offline Edition:** 8 GB RAM or more (Vulkan-compatible GPU with 4 GB+ VRAM recommended for instant ~0.5–2s translation; automatically falls back to CPU)
- **API Edition:** Internet connection and an API key (e.g., Google Gemini API)

## About

LiveTrans translates manga, webtoons, games, videos, and highlighted text into smooth, natural Thai without breaking your reading flow. It includes four core modes: Magic In-Image Translation (`Alt+W`) with auto-follow scroll and an X-Ray original-text loupe, Live Region Subtitle (`Alt+L`), Quick Snip + Vocabulary Deep Dive (`Alt+Q`), and Highlighted Text Translation (`Ctrl+Alt+C`), along with eye-care themes, click-through overlays, translation history, and a custom glossary.

The source code is maintained separately.
